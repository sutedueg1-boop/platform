## 1. نظرة عامة على النظام (Executive Overview)

### 1.1 الغرض والهدف

**نظام تصاريح العمل الرقمي** هو تطبيق ويب إنتاجي متكامل مصمم خصيصاً لرقمنة وأتمتة دورة حياة تصاريح العمل داخل مصنع السويدي بوليمرز، وذلك استبدالاً للنماذج الورقية التقليدية بما يضمن:

- **السرعة:** إرسال طلب تصريح في ثوانٍ من أي جهاز متصل بالشبكة الداخلية للمصنع
- **الشفافية:** تتبع حالة كل تصريح لحظياً من قِبَل العامل والمشرف في نفس الوقت
- **الحماية:** تطبيق صلاحيات متعددة المستويات تمنع التعديل غير المصرح به
- **التوثيق:** أرشفة تلقائية لجميع التصاريح في ملف Excel قابل للتدقيق والمراجعة

### 1.2 أنواع التصاريح المدعومة

| الكود | نوع التصريح | الاستخدام |
|-------|------------|-----------|
| `general` | تصريح عام | أعمال التفريغ والنقل العام |
| `height` | عمل على ارتفاع | السقالات وأعمال الارتفاع |
| `confined` | أماكن مغلقة | الدخول للأوعية والأنفاق |
| `excavation` | حفر | أعمال الحفر والتمديدات |
| `lifting` | رفع | الونش والرافعات |
| `hot` | عمل ساخن | اللحام والقطع والحرق |
| `loto` | فصل وعزل طاقة | إجراءات LOTO الكاملة |

### 1.4 المطابقة مع المعايير الأمنية

| المعيار | التطبيق | الحالة |

| **OWASP A08** — Race Conditions | Write Queue (Promise Chain) على كل عمليات الكتابة | ✅ مُطبَّق |

## 2. دليل المستخدم الميداني (User Manual)

### 2.1 دخول العمال والمهندسين (بدون كلمة مرور)

> **المبدأ:** كل عامل يدخل بكوده الوظيفي فقط — لا كلمة مرور مطلوبة.

#### خطوات الدخول للمرة الأولى:

```
1. افتح المتصفح وأدخل عنوان النظام (المثال: http://192.168.1.100:3000)
2. تظهر شاشة "مرحباً بك"
3. أدخل كودك الوظيفي (مثال: EMP-001)
4. إذا كان الكود جديداً: أدخل اسمك الرباعي ورقم هاتفك وقسمك
5. اضغط "حفظ وتسجيل الدخول ✓"
6. ستدخل النظام وتُملأ بياناتك تلقائياً في كل نموذج طلب
```

#### للدخول في المرات التالية:

```
1. أدخل كودك الوظيفي فقط → اضغط "تسجيل الدخول ←"
2. يدخل النظام فوراً دون إعادة إدخال البيانات
```

#### إرسال طلب تصريح:

```
1. من تبويب "📋 نموذج طلب"
2. اختر نوع التصريح المطلوب (عام / ارتفاع / ساخن / ...)
3. أكمل الحقول: القسم، الوردية، التاريخ، مكان العمل، وصف العملية
4. أجب على قائمة التحقق (نعم / لا / لا ينطبق)
5. أضف تقييم المخاطر إن وجد
6. اضغط "إرسال الطلب للمشرف"
7. احتفظ برقم التصريح (مثال: WP-2026-0045)
```

#### متابعة حالة التصريح (سجل تصاريحي):

```
1. من تبويب "📁 سجل تصاريحي"
2. تظهر جميع تصاريحك مع حالاتها:
   ⏳ قيد الانتظار   →  بانتظار موافقة المشرف
   ✅ موافق عليه    →  يمكن بدء العمل
   ❌ مرفوض        →  راجع سبب الرفض وأعد الإرسال
   🔒 مغلق         →  اكتمل العمل أو أُغلق جبرياً
```

### 2.2 دخول المشرفين (Supervisor / Admin)

```
1. من شاشة الدخول الأولى: اضغط "🛡️ دخول المشرفين / الإدارة"
2. أو من التبويبات: "🛡️ لوحة المشرف"
3. أدخل اسم المستخدم وكلمة المرور
4. اضغط "دخول"
```

#### مراجعة الطلبات والموافقة:

```
1. تظهر لوحة التحكم بجميع الطلبات الواردة
2. استخدم فلاتر النوع والحالة لتصفية الطلبات
3. لكل طلب "قيد الانتظار":
   - أدخل اسم مشرف السلامة واسم مدير المنطقة (اختياري)
   - اضغط "✓ موافقة" أو "✗ رفض"
   - عند الرفض: أدخل سبب الرفض ثم "تأكيد الرفض"
4. للطلبات "الموافق عليها":
   - بعد انتهاء العمل: اضغط "اكتمل بأمان" أو "لم يكتمل" أو "إغلاق جبري"
5. لتصدير سجل Excel: اضغط "⬇ تصدير Excel"
```

### 2.3 دخول المدير العام (Super Admin)

> **الصلاحيات الحصرية:** إدارة حسابات المشرفين وإضافتهم وحذفهم وتغيير كلمات مرورهم.

```
1. سجّل الدخول بحساب superadmin
2. يظهر تبويب إضافي "👥 المستخدمون" (لا يظهر لغير superadmin)
3. من لوحة إدارة المستخدمين:
   - إضافة مشرف جديد: أدخل الاسم واسم المستخدم وكلمة المرور والدور
   - تغيير كلمة المرور: اضغط "🔑 كلمة المرور" بجانب اسم المستخدم
   - حذف مستخدم: اضغط "🗑 حذف" (لا يمكن حذف حساب superadmin)
```

#### هيكل الأدوار والصلاحيات:

```
superadmin  ──┬── إدارة المستخدمين (إضافة / حذف / تعديل)
              ├── مراجعة جميع التصاريح
              └── تصدير Excel

admin       ──┬── مراجعة التصاريح والموافقة / الرفض
              ├── إغلاق التصاريح
              └── تصدير Excel

supervisor  ──┬── مراجعة التصاريح والموافقة / الرفض
              └── إغلاق التصاريح

employee    ──┬── إرسال طلبات التصاريح
              └── عرض سجل تصاريحه الشخصي
```

### 3.3 تشغيل النظام على الشبكة الداخلية للمصنع

#### المتطلبات:
- **Node.js** النسخة 18 أو أحدث
- جهاز كمبيوتر/سيرفر متصل بشبكة المصنع الداخلية (LAN)
- المنفذ `3000` مفتوح على الـ Firewall

#### خطوات التشغيل:

```powershell
# 1. الانتقال لمجلد المشروع
cd C:\work-permits-app

# 2. تثبيت التبعيات (مرة واحدة فقط)
npm install

# 3. تشغيل الخادم
node server.js

# الخادم يعمل على: http://localhost:3000
```

#### الوصول من الشبكة الداخلية:

```
# معرفة IP الجهاز المُشغِّل للسيرفر
ipconfig  →  ابحث عن IPv4 Address

# مثال: IP الجهاز = 192.168.1.50
# رابط الوصول من أي جهاز في المصنع:
http://192.168.1.50:3000
```

#### التشغيل التلقائي مع بدء Windows:

```powershell
# إنشاء ملف start_server.bat في مجلد المشروع
@echo off
cd /d "C:\work-permits-app"
node server.js
pause

# ثم أضفه لـ Windows Startup عبر:
# shell:startup  →  انسخ الملف هناك
```
